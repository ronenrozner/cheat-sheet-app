# Vim

## Modes

- Normal mode: press `Esc` to return to normal mode.
- Insert mode: press `i` to enter insert mode.

## Editing

| Key | Action |
| --- | --- |
| `i` | Insert mode |
| `A` | Append at end of line |
| `Esc` | Return to normal mode |

## Saving

- `:w` to write (save).
- `:q` to quit.
